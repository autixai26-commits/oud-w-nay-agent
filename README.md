# الجزء الأول: الحسابات والمفاتيح

**هاد الجزء إلك أنت.** بدنا نفتح ٦ حسابات ونجيب منها ٩ مفاتيح. خُد وقتك — كل خدمة لحالها ما بتاخد أكثر من ٥ دقايق.

## قبل ما تبلّش — قاعدتان مهمّتان

1. **المفتاح بينعرض مرة وحدة بس.** أغلب هالخدمات بتوريك المفتاح لحظة إنشائه وبعدها بتخبّيه للأبد. إذا سكّرت الصفحة قبل ما تنسخه، بتضطر تعمل مفتاح جديد. فجهّز مكان تلزق فيه.

2. **وين تلزق:** بمجلد المشروع في ملف اسمه `.env.example`. انسخه وسمّي النسخة `.env` (بنقطة بالأول، بدون أي إشي بعد `env`). كل مرة تجيب مفتاح، افتح `.env` والزقه بعد علامة `=` المناسبة، بدون مسافات وبدون علامات تنصيص.

الشكل الصحيح:

```
TELEGRAM_BOT_TOKEN=7123456789:AAF-xxxxxxxxxxxxxxxxxxx
```

الشكل الغلط:

```
TELEGRAM_BOT_TOKEN = "7123456789:AAF-xxxxxxxxxxxxxxxxxxx"
```

> **تحذير:** ملف `.env` فيه كل أسرارك. ما تبعته لحدا، ما تنشره، وما تحطه بصورة أو رسالة. النظام معمول بحيث ما ينطبع أي مفتاح بأي مكان — لا باللوق ولا برسائل الخطأ.

## ١. بوت تيليجرام — من BotFather

أسهل واحد، وكله من داخل تطبيق تيليجرام.

1. افتح تيليجرام وابحث عن **`@BotFather`** — الحساب الرسمي، إله علامة ✅ زرقا جنب الاسم.
2. اضغط **Start**.
3. ابعتله: `/newbot`
4. رح يسألك عن **اسم البوت** — الاسم اللي بيشوفه الزبون. اكتب: `عود وناي`
5. رح يسألك عن **يوزرنيم البوت** — لازم ينتهي بـ `bot` ويكون فريد. جرّب `OudWNayBot`، وإذا محجوز جرّب `OudWNayRestaurantBot`.
6. رح يبعتلك رسالة فيها سطر طويل شكله `7123456789:AAF-xxxxxxxxxxxxxxx` — **هاد هو التوكن.** انسخه كامل، من أول رقم لآخر حرف، بدون مسافات.
7. الزقه بـ `.env` عند `TELEGRAM_BOT_TOKEN=`

### إعدادات إضافية (اختيارية بس منيحة)

وأنت لسا عند BotFather:

- `/setdescription` ← اختار بوتك ← اكتب: `احجز طاولتك في عود وناي — مطعم لبناني بالفحيص`
- `/setuserpic` ← اختار بوتك ← ابعت شعار المطعم

## ٢. Supabase — قاعدة البيانات

هون بتنحفظ الطاولات والحجوزات والمنيو.

1. روح على **https://supabase.com** واضغط **Start your project**.
2. سجّل دخول بحساب GitHub أو بإيميلك.
3. اضغط **New project**.
4. عبّي:
   - **Name:** `oud-w-nay`
   - **Database Password:** اضغط **Generate a password** وانسخها لمكان آمن. (ما رح نحتاجها بالنظام، بس بتحتاجها لو بدك تدخل على القاعدة مباشرة يوم من الأيام.)
   - **Region:** اختار **Frankfurt (eu-central-1)** — أقرب واحد للأردن.
5. اضغط **Create new project** وانتظر دقيقتين لحد ما يخلص التجهيز.
6. من القائمة اليسار: **Project Settings** (ترس ⚙️ تحت) ← **API**.
7. رح تلاقي:
   - **Project URL** — شكله `https://abcdefghijk.supabase.co`
     الزقه عند `SUPABASE_URL=`
   - تحت **Project API keys** في مفتاحين. بدنا **`service_role`** — مش `anon`.
     اضغط **Reveal** جنبه، انسخه، والزقه عند `SUPABASE_SERVICE_KEY=`

> **انتبه:** مفتاح `service_role` بيعطي صلاحية كاملة على القاعدة. بينحط بالباك إند بس — ولا مرة بصفحة ويب.

## ٣. OpenRouter — الذكاء الاصطناعي للأسئلة الحرة

OpenRouter بوابة واحدة بتوصلك لموديلات كتير بمفتاح واحد.

1. روح على **https://openrouter.ai** وسجّل حساب.
2. **مهم:** لازم تشحن رصيد قبل ما يشتغل المفتاح. من صورتك أعلى اليمين ← **Credits** ← اشحن **$10** (بتكفي شهور للاستخدام العادي).
3. من القائمة: **Keys** — أو روح مباشرة على https://openrouter.ai/keys
4. اضغط **Create Key**.
5. **Name:** `oud-w-nay`
6. رح يظهر مفتاح بيبلّش بـ `sk-or-v1`. **هاي المرة الوحيدة اللي بتشوفه فيها.** اضغط زر النسخ.
7. الزقه عند `OPENROUTER_API_KEY=`

المتغيّر `OPENROUTER_MODEL` خليه زي ما هو (`anthropic/claude-sonnet-4-5`). تقدر تبدّل الموديل من هون بدون ما تلمس الكود.

> **ملاحظة:** ما في حساب OpenAI بهذا المشروع إطلاقاً. الأسئلة الحرة عبر OpenRouter، وتحويل الصوت لنص والنص لصوت الاثنين عبر ElevenLabs.

## ٤. ElevenLabs — تحويل الصوت لنص والنص لصوت

هاد اللي بيخلّي البوت يفهم الرسائل الصوتية ويرد برسالة صوتية بصوت طبيعي. **نفس المفتاح بيخدم الاتجاهين.**

**المفتاح:**

1. روح على **https://elevenlabs.io** وسجّل حساب.
2. اضغط على صورتك أو الأحرف الأولى من اسمك (أعلى اليمين) ← **API Keys** ← **Create API Key** ← سمّيه `oud-w-nay` ← انسخه.
3. الزقه عند `ELEVENLABS_API_KEY=`

**معرّف الصوت:**

1. من القائمة اليسار اضغط **Voices**.
2. إذا عندك الصوت اللي استخدمته بالمشروع السابق، رح تلاقيه بقائمة **My Voices**.
3. اضغط النقاط الثلاث `⋮` جنب الصوت ← **Copy Voice ID**. (أو افتح الصوت وشوف `Voice ID` بصفحته.)
4. المعرّف شكله سلسلة حروف وأرقام زي `21m00Tcm4TlvDq8ikWAM`.
5. الزقه عند `ELEVENLABS_VOICE_ID=`

> إذا ما لقيت الصوت القديم، اختار أي صوت عربي من **Voice Library** وانسخ معرّفه — بنقدر نبدّله بأي وقت من ملف `.env` بدون تعديل كود.

## ٥. أسرار الأدمن — بتخترعها أنت

مش من خدمة، إنت بتختارها.

**`ADMIN_SETUP_SECRET`** — كلمة سر لمرة وحدة، بتستخدمها إنت وشريكك عشان تسجّلوا حالكم كأدمنية بالبوت. اختار نص طويل عشوائي، مثلاً `oud-nay-2026-x7k9m2p4q`. الزقه عند `ADMIN_SETUP_SECRET=`

**`ADMIN_DASHBOARD_PASSWORD`** — كلمة سر صفحة عرض الحجوزات. اختار وحدة تقدر تحكيها للموظفين، مثلاً `OudNay2026!`. الزقه عند `ADMIN_DASHBOARD_PASSWORD=`

## ٦. Render — استضافة الباك إند

هون بيشتغل البوت فعلياً على مدار الساعة.

1. روح على **https://render.com** وسجّل بحساب GitHub.
2. **لا تعمل إشي هلأ** غير إنك تتأكد إنك داخل. رح نرجعلها بالمرحلة الأخيرة لما يكون الكود جاهز.
3. **مهم — الخطة:** لما نوصل لخطوة النشر، لازم تختار خطة **Starter** بـ **$7 شهرياً**، مش المجانية.

   **ليش؟** الخطة المجانية بتنيّم الخدمة بعد ١٥ دقيقة بلا حركة. يعني: التذكيرات ما بتوصل، الإلغاء التلقائي ما بيشتغل، وأول زبون بيراسل البوت بعد فترة هدوء بيستنى ~٥٠ ثانية لحد ما يرد. هاد مش مقبول لنظام حجوزات.

---

## ٧. Netlify — استضافة الموقع

1. روح على **https://netlify.com** وسجّل بحساب GitHub.
2. زي Render — بس تأكد إنك داخل. رح نرجعلها بمرحلة النشر.
3. الخطة المجانية كافية تماماً هون، لأن الموقع صفحات ثابتة.

# ✅ قائمة التحقق

قبل ما نكمّل، افتح `.env` وتأكد إن كل سطر عنده قيمة:

| المتغيّر | من وين | جاهز؟ |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | BotFather | ☐ |
| `OPENROUTER_API_KEY` | openrouter.ai/keys | ☐ |
| `OPENROUTER_MODEL` | جاهز مسبقاً (`anthropic/claude-sonnet-4-5`) | ☑ |
| `ELEVENLABS_API_KEY` | elevenlabs.io | ☐ |
| `ELEVENLABS_VOICE_ID` | elevenlabs.io ← Voices | ☐ |
| `SUPABASE_URL` | Supabase ← Settings ← API | ☐ |
| `SUPABASE_SERVICE_KEY` | Supabase ← Settings ← API (`service_role`) | ☐ |
| `ADMIN_SETUP_SECRET` | إنت بتخترعها | ☐ |
| `ADMIN_DASHBOARD_PASSWORD` | إنت بتخترعها | ☐ |
| `PUBLIC_WEB_URL` | لاحقاً — بعد نشر Netlify | ⏳ |
| `BACKEND_URL` | لاحقاً — بعد نشر Render | ⏳ |
| `RESTAURANT_PHONE` | جاهز مسبقاً | ☑ |

آخر اثنين (`PUBLIC_WEB_URL` و `BACKEND_URL`) خليهن فاضيين — بنعبّيهن بمرحلة النشر.
